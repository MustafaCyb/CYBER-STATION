## Overview

**Python Email Extractor** is a desktop GUI application that extracts email addresses from web pages. Built with customtkinter for a modern dark-themed interface, it supports multi-threaded URL crawling for fast results.

## Features

- **Modern GUI** — customtkinter-based interface with dark theme
- **Multi-Threaded Crawling** — parallel URL processing for speed
- **Regex-Based Extraction** — robust email pattern matching
- **HTML Report Export** — generates formatted reports with extracted emails
- **URL Input** — paste single URLs or import from file

## Screenshot

The application features a clean, dark-themed interface with input fields for URLs, a progress indicator, and a results panel showing extracted emails.

## Installation

```bash
git clone https://github.com/MustafaCyb/Python-Email-Extractor.git
cd Python-Email-Extractor
pip install -r requirements.txt
python main.py
```
