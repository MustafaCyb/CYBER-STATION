## Overview

**Digital Forensic Tool Kit** is a lightweight Python toolkit designed for digital forensics investigations. It provides essential utilities for memory analysis, file system examination, and data integrity verification.

## Features

- **Memory Analysis** — examine volatile data and memory dumps
- **File Examination** — inspect file metadata, signatures, and content
- **Hash Verification** — generate and verify MD5, SHA-1, SHA-256 hashes for evidence integrity
- **Simple CLI** — easy-to-use command-line interface for quick forensic operations

## Use Cases

This toolkit is ideal for:
- Digital forensics students learning investigation techniques
- Quick triage during incident response
- Evidence integrity verification in chain-of-custody workflows
- File signature analysis and metadata extraction

## Getting Started

```bash
git clone https://github.com/MustafaCyb/Digital-Forensic-Tool-Kit.git
cd Digital-Forensic-Tool-Kit
python main.py
```
