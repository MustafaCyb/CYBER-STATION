## Overview

**Cyber Station Slides** is the central repository for all lecture presentations delivered through the Cyber Station platform. It contains slide decks covering a wide range of cybersecurity topics.

## Available Lectures

1. **CYBER-101** — Introduction to cybersecurity fundamentals
2. **Cryptography for Hackers** — Practical cryptography from an offensive perspective
3. **DLLs in Practice** — Understanding DLL hijacking and side-loading
4. **Real World Phishing Attacks** — Anatomy of modern phishing campaigns
5. **Snort Rules** — Writing effective IDS/IPS rules with Snort
6. **TwinSanity Recon Project** — Deep dive into the TwinSanity reconnaissance tool

## Structure

Each lecture folder contains the presentation files, any supporting materials, and scripts used during live demonstrations.

## Contributing

New lecture slides can be added by creating a folder with the lecture name and placing presentation files inside. A corresponding Markdown file should be added to the Cyber Station website content.
