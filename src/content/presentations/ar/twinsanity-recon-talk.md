## نظرة عامة على المحاضرة

تستعرض محاضرة **معمارية منصة TwinSanity Recon** التصميم البرمجي المعياري لمنصة استطلاع حديثة. نوضح فيها تقنيات جمع النطاقات الفرعية السلبية من أكثر من 10 مصادر مختلفة، وحل سجلات DNS بشكل متزامن، ورسم خرائط الـ CVEs، واستدعاء واجهات Shodan، وإدارة نماذج الذكاء الاصطناعي (بما في ذلك نماذج Ollama المحلية) لتوليد التقارير الأمنية.

---

## تفاصيل عروض الشرائح

### الجزء 1: نظرة عامة على المنصة
*   **ما هي منصة TwinSanity Recon؟** منصة ويب متكاملة لجمع معلومات النطاقات واكتشاف الثغرات الأمنية، تجمع بين أتمتة الاستطلاع (OSINT) والتحليل الذكي المعتمد على نماذج اللغة الكبيرة (LLMs).
*   **الفئة المستهدفة:** مهندسو اختبار الاختراق، صائدو الثغرات (Bug Bounty Hunters)، وفرق الأمن السيبراني في الشركات.
*   **أبعاد المشروع:** مبني بلغة Python 3.10+، يدمج أكثر من 10 محركات بحث، و5 مزودي ذكاء اصطناعي، ويدعم تشغيل النماذج محلياً، مع لوحة تحكم تفاعلية مبنية على Flask عبر تقنية WebSockets.

### الجزء 2: قدرات الاستطلاع وجمع البيانات
*   **جمع النطاقات الفرعية (Subdomain Enum):** تجميع سلبي للبيانات من مصادر متعددة تشمل `crt.sh`, `SecurityTrails`, `VirusTotal`, `Chaos`, `HackerTarget`, و `AlienVault OTX`.
*   **حل سجلات DNS المتزامن:** الاستعلام المتوازي عن سجلات متعددة (A, AAAA, CNAME, MX, NS, TXT) لزيادة السرعة والكفاءة.
*   **الفحص النشط (HTTP Probing):** فحص المنافذ المفتوحة، وتحديد أكواد الاستجابة وعناوين الصفحات، واستخلاص البصمات التقنية للخدمات.
*   **رسم خرائط الثغرات:** استخراج الروابط والأرشيفات من Wayback Machine و CommonCrawl وفحص الثغرات (CVEs) بالربط مع قاعدة بيانات NIST NVD API.

### الجزء 3: محرك التحليل بالذكاء الاصطناعي
*   **إدارة نماذج الذكاء الاصطناعي:** تكامل مرن مع خدمات السحابة (GPT, Claude, Gemini) يتم تهيئته عبر ملف `config.yaml`.
*   **أمان البيانات بالذكاء الاصطناعي المحلي:** اكتشاف واستخدام النماذج المحلية التي تعمل عبر **Ollama** تلقائياً، لضمان خصوصية عمليات الفحص وعدم إرسال بيانات العميل للسحابة.
*   **دور التحليل بالذكاء الاصطناعي:** قراءة مخرجات الفحص الخام، تحديد مستويات الخطورة، ربط الثغرات بمراجع NIST، وكتابة توصيات ترقيع الثغرات.
*   **مساعد الدردشة الأمني:** واجهة محادثة ذكية لمناقشة نتائج الفحص واقتراح سيناريوهات الاختراق أو الإصلاح.

### الجزء 4: معمارية لوحة التحكم
*   **تحديثات البث المباشر (WebSockets):** بث فوري لنتائج تقدم الفحص وعرض النطاقات المكتشفة والثغرات مباشرة للمستخدم.
*   **الأدوات المدمجة:**
    *   **مستكشف Shodan:** للبحث عن الأصول والخدمات المكشوفة التابعة للشركة على الإنترنت.
    *   **مستكشف الـ CVE:** تصفح والبحث في ثغرات NIST وتصنيفها حسب الخطورة.
    *   **TwinSanity Island:** خريطة تفاعلية تعرض العلاقات بين النطاقات وحالتها الأمنية.

### الجزء 5: البناء والتشغيل السريع
*   **خطوات التشغيل:**
    ```bash
    git clone https://github.com/MustafaCyb/TwinSanity-Recon.git
    cd TwinSanity-Recon
    python -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    python run_dashboard.py
    ```
*   **إعداد `config.yaml`:** إدخال مفاتيح الواجهات البرمجية (API Keys) لـ Shodan و VirusTotal، وضبط محركات البحث المفعلة ومحددات نماذج الذكاء الاصطناعي.
