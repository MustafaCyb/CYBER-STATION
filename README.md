# 🌌 CYBER-STATION

The official Cyber Station website — a bilingual (English & Arabic) platform showcasing cybersecurity articles, presentations, and projects. Built with [Astro](https://astro.build/) for high performance and a dynamic, space-themed user interface.

## ✨ Features
- **Bilingual Support:** Full content support for both English and Arabic.
- **Content Types:** Beautifully designed sections for Articles, Presentations, and Projects.
- **Space-Themed UI:** Advanced animations, glassmorphism design, and a responsive star canvas background.
- **Dark & Light Mode:** Toggleable themes with synchronized aesthetics.

## 🚀 Local Development

To run this project locally, make sure you have [Node.js](https://nodejs.org/) installed, then follow these steps:

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start the development server**
   ```bash
   npm run dev
   ```

3. **Build for production**
   ```bash
   npm run build
   ```
